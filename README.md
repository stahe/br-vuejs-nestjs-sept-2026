# Um exemplo cliente/servidor - Vue.js / NestJS

Este repositório acompanha o curso **“Um exemplo cliente/servidor - Vue.js / NestJS”**, disponível online em:

**➡️ [https://stahe.github.io/br-vuejs-nestjs-sept-2026/](https://stahe.github.io/br-vuejs-nestjs-sept-2026/)**

## Visão geral

Este curso detalha o desenvolvimento de uma aplicação cliente/servidor completa, **RdvMedecins** (agendamento de consultas médicas), por meio de:
- um servidor **[NestJS]** que expõe uma API REST (autenticação JWT, banco de dados MySQL, entidades TypeORM);
- um cliente **[Vue.js] 3** (Composition API, `<script setup>`, TypeScript) que consome essa API, com gerenciamento de sessão, internacionalização em francês/inglês (`vue-i18n`) e uma interface adaptada ao papel do usuário conectado (administrador/usuário).

Este curso retoma e aprofunda as funcionalidades de “lógica de negócio” de uma aplicação desenvolvida em versões anteriores do curso (AngularJS 1.x, depois Angular e React), para facilitar uma comparação didática entre esses diferentes frameworks de cliente, com o servidor NestJS permanecendo o mesmo ao longo de todo o curso.

Cada capítulo do curso apresenta comentários linha por linha dos trechos de código mais significativos, em seções intituladas “Vamos comentar este código”.

## Sumário do curso

1. Introdução (arquitetura geral, tecnologias utilizadas)
2. Configuração do ambiente de desenvolvimento
3. O servidor NestJS da aplicação RdvMedecins
4. Introdução ao framework Vue.js
5. O cliente Vue.js da aplicação RdvMedecins
6. Conclusão
